# Eclipse Magazine

Eclipse Magazine is a static website. It does not need Node.js, a database, or environment variables.

## Start the site locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy the site

Publish the contents of this folder as the site root. The root must contain:

- `index.html` — the default page loaded at the site URL
- `eclipse-cover-art.svg` — the cover illustration used by the page

`eclipse-magazine.html` is kept as a direct alternative URL. The homepage now starts from `index.html`.
